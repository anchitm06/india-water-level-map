# India groundwater level map

Interactive district-level map of India's groundwater depth (m below ground level), with a
pre/post-monsoon year slider and per-district history charts. Static site for GitHub Pages.

## Status
- Frontend (Vite + TypeScript + MapLibre + Chart.js): working.
- `public/data/*` is currently **synthetic placeholder data** (a 1° grid, not real districts),
  generated by `pipeline/generate_placeholder.py`. The UI shows a banner while this is the case.
- `pipeline/fetch.py` (India-WRIS download) is written from the public swagger and tested only on a small
  sample (`pipeline/tests/`). It has never reached the live API: the cloud sandbox cannot connect to
  `indiawris.gov.in`, so run it locally. It needs `pipeline/targets.csv` (state,district,agency).
  `pipeline/aggregate.py` is untested against real readings.
- Still needed: real district boundaries (`public/data/districts.geojson`, properties `id`, `name`, `state`).

## Develop
    npm install
    npm run dev        # http://localhost:5173
    npm run build

## Data pipeline
    pip install -r pipeline/requirements.txt
    python pipeline/fetch.py       # -> pipeline/raw/readings.csv  (station_id,lat,lon,date,level_m_bgl)
    python pipeline/aggregate.py   # -> public/data/levels.json

## Deploy
`.github/workflows/deploy.yml` publishes `dist/` to GitHub Pages on push to `main`
(enable Pages with source "GitHub Actions" in the repo settings).
